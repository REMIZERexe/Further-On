# What is this?
Create: Further On! is an addon for Create mod, focused on detailed technological progress that goes after what Create gives. Refining oil, creating new materials, new engines, electricity, new power sources and SO much more! Inspired by beloved addons, it gives an immersive realistic experience by creating an interesting progression tree and various fun mechanics.
